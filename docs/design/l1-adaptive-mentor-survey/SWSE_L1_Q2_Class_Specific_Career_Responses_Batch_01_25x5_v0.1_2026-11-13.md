# SWSE L1 Q2 — Class-Specific Career Responses, Batch 1 (Parents 01–25)

**Local working draft | 2026-11-13 | No Git commit/push | Editorial review pending**

## Authority and display contract

- Source: the already established 97-parent Q2 career answer bank v0.4. This file covers its **first 25 parents only** and preserves their original universal wording for comparison.
- Exactly **five independently authored first-person variants** per parent: Jedi, Noble, Scoundrel, Scout, Soldier (**125 new responses**).
- All five variants of a given parent map to **one and the same canonical parent ID**. Class modifies phrasing and possible approach, not career identity or career eligibility.
- In the actual conversation, show **only the chosen class quote**. Parent names, class labels, IDs and numbering in this document are strictly for developer/editor review, never adjacent UI labels.
- The five mentors already have their fixed approved Q2 stage-framing lines; **the player answers are not phrased as the mentors speaking**.
- An answer states the character's **aspiration**, not current possession of a skill, talent, feat, Force power, equipment, office, allegiance, class level, or prestige status.
- Do not infer intent from any unselected variants or auto-granted feats/talents. Only explicit selection is evidence. Q2 ranking by class/species/attributes/Q1 remains advisory; all 97 parents remain browsable.
- This file is an **editorial dialogue layer**, not a replacement archetype registry, new score taxonomy, or production code. These variants are proposed for user approval.
