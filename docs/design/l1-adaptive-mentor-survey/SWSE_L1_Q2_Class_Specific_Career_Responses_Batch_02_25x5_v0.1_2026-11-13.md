# SWSE L1 Q2 — Class-Specific Career Responses, Batch 2 (Parents 26–50)

**Local working draft | 2026-11-13 | No Git commit/push | Editorial review pending**

## Authority and display contract

- Source: established 97-parent Q2 career answer bank v0.4. This batch covers parents **26–50** and preserves the original universal quotes unchanged for comparison.
- Exactly **five independently authored first-person variants** per parent: Jedi, Noble, Scoundrel, Scout, Soldier (**125 new responses**).
- All five variants of each career map to one canonical parent ID. Class changes the speaker’s perspective, not the career identity or eligibility.
- The player sees **only** the selected class-specific quote as an answer. Developer-only career labels, IDs and numbers are never displayed as answer labels.
- These are **player response statements**, not lines spoken by the five Mentors. Approved Mentor Q2 introductions remain fixed.
- Respondents express aspirations, not already-owned skills, features, feats, Force powers, equipment, military rank or prestige achievements.
- Selected answers alone record explicit career intent; unselected quotes, suggested ranking and browsing generate no preference evidence.
- The canonical registry remains the sole parent-identity authority; this is a local editorial dialogue layer, not a new ontology or production implementation.
