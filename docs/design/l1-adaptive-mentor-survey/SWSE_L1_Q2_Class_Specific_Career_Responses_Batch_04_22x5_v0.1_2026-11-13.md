## Authority and player display contract

- Source: 97-parent universal Q2 bank v0.4. This batch contains its **parents 76–97** and preserves each universal response verbatim.
- Exactly **five original first-person class variants** per career: Jedi, Noble, Scoundrel, Scout, Soldier (**110 newly authored lines**).
- Every response is keyed to the **same canonical parent ID**, independent of starting class. Unconventional class/career combinations remain selectable.
- Player UI displays **only the chosen class-specific quote**, without parent name, ID, numbering, scoring tags, or class labels.
- These are **character response choices**, not Mentor dialogue. The approved fixed Q2 Mentor introductions remain separate.
- Statements express a future desired calling; they do **not** imply that the character already has a trained skill, talent, feat, Force power, prestige class, faction rank, or equipment.
- Class-specific dialogue does not alter canonical career identity; choosing a response deliberately records its parent aspiration. Suggestions/browsing do not.
- `data/archetypes.json` is the parent SSOT; this is a presentation/content layer only. Parent mapping checked against the previously verified 97-parent snapshot. Rules/legal prerequisites require separate verification.
