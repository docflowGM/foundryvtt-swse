## Essential cross-book differences

The B1 squad on printed p217 is **three B1 units** with squad-only source statistics; the Clone Wars squad used four. The p220 alternate squad citation from the source census is not supported by the rendered p220 page and has not created a duplicate. The GAT at printed p216 is a **vehicle** with 175 HP and DR10, not a droid creature. Automated Sentry Gun p98 base Reflex 15 changes to 20 in the p175 encounter only through +5 cover. Sniper Droideka p55 is different from the p211 encounter Droideka and Core stock. Tactical Droid price **14,005** retains the visual correction.
