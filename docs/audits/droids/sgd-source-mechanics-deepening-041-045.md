## 041 TT-8L Gatekeeper (pp.148–149)

Four protocol claims: Eavesdrop (swift Perception), Intimidate (two swift Persuasion), Sense Deception (reaction) and Stubborn (no action). **Existing `SGD-041-STUBBORN-TARGET-CONFLICT` still unresolved:** main protects gatekeeper's OWN Will vs Persuasion, protocol protects MASTER'S Will. No blanket bonus to both.

**Advance Scout** removes the STATIONARY stock droid from base, mounts it within an ACTUAL speeder or other vehicle, and retrains Knowledge bureaucracy into Pilot and related feat; optional skill focus change. **Communications Antenna** requires new modular comlink/hypertransceiver, skill/Skill Focus retraining and DC30 Mechanics/2d for hypertransceiver, DC15 Mechanics/10m for antenna. Pod attach is FULL-ROUND and removal SWIFT. **Security Camera** adds video/holorecorder, physically mounts droid at an installed location with network/wireless integration. **Stock speed is zero**, no hero creation authorized.

## 042 V2-Series Commando (pp.150–151)

Five protocols: move, Avoid Surprise, Patrol Duty, Silent Action (+2 to aided Stealth), and Support Fire (held rifle +2 for 3d8). **Bomb Disposal Unit** adds reinforced courier compartment and cryogas containment; deliberately detonating stored explosives INSIDE unit as free action DESTROYS it. **EVA Shipjacker** adds small jets DC25 Mechanics/30m, one starship square per FULL-ROUND, Acrobatics vs ship Reflex to attach and separate planting DC = 10 × ship/droid size-category difference; cockpit/command blast scope limited. **HALA** repulsor modification DC25 Mechanics/1h, DC20 Jump to select landing area (100m drift per failure margin) then DC30 Pilot for safe landing, failure maximum falling damage. These are optional configurations, not automatic flying, explosives or free attacks. Hero path recommends soldier, later scout/elite trooper/independent droid acquired normally.

## 043 V6-Series Pilot (pp.152–153)

Six protocol actions: move, Copilot, friendly-computer routine command, Recharge Shields DC20 (+5 SR), Regulate Power DC20 (+1 condition), and Stay on Target (Pilot -5 opposed dogfight).

**Gunner:** REPLACE Weapon Proficiency simple with Vehicular Combat, install turret mag clamps DC30 Mechanics/2h, program DC25 Use Computer/1h, choose +2 to EITHER attack OR damage once/turn while physically installed in turret. Under optional *Starships of the Galaxy* alternate maneuver system, instead grant gunner-descriptor maneuvers up to INT modifier min1, not both regimes. **Speeder Pilot:** interface DC25 Mechanics/1h and DC20 Use Computer/30m, equivalent Vehicular Combat only while piloting repulsorlifts. **Hijacker:** sleeper coordinates via opposed Use Computer/Will (30m), jump shuts down droid; second opposed check can reset original destination and erase memory. Both checks can fail; no universal control.

Hero route is a scoundrel recommendation, must buy optional astrogation buffer and legal pilot feats.

## 044 X-1 Viper (pp.154–155)

Five protocol actions: move, Avoid Surprise, Double Attack (separate twin cannon and grenade launcher), Patrol Duty, Rapid Shot. **Molecular Shielding** only reflects a MISSED ranged ENERGY attack using attacker's own attack roll MINUS 10 vs attacker's Reflex. This is not full reflection of hits or force attacks.

**Deep Sea Diver:** seal internals, add webbing/buoyancy DC25 Mechanics/2d, retrain Swim and Skill Focus (Swim). **Jawa Transport:** clear chassis DC30 Mechanics/4h for four Small or two Medium occupants and 100kg cargo; manual override STANDARD action/DC20 Use Computer. **Reconstruction:** clear chassis DC30 Mechanics/4h for 500kg cargo and optional pods of +250kg each, DC25 Mechanics/1h per pod, number at most half STR modifier (min1). Encounter-only hostage shield example is contextual, not baseline auto action. Hero model prohibited; weapon mounts require independent verification.

## 045 XLT-014 Labor (pp.156–157)

Five protocols: move walking or LIMITED hover, Avoid Surprise, Improve Access, Issue Routine Command, Quick Scan (DC20 Perception within six squares, reduces master penalties from cover/concealment by half; separate Use Computer check retrieves network data in half time).

**Chauffeur:** REPLACE remote receiver with basic processor and claws with hands, install sensors/comlink; either retrain Use Computer+Skill Focus to Pilot OR install scomp and retain computer focus, not both. **Infiltrator:** REPLACE remote processor with heuristic, add sound baffling 200 credits/DC15 Mechanics/1h permitting Stealth reroll keep better; add sensors/darkvision; change Skill Focus Perception into Skill Training Stealth and purchase security kit. **Mechanic's Assistant:** heuristic processor, hand/tool replacement, diagnostics, 5kg storage for possessed toolkit, REPLACE Armor Proficiency light with Skill Training Mechanics. Heroic route uses stock labor chassis replacing basic with remote receiver and Quick Scan, buys video recorder rather than silently acquiring it.
