**Phase:** E3-A3 only. Equipment posture/readiness, durable equipment state, transactions, action spending, encumbrance, Near-Human, the droid refactor and Foundry certification are **not** authorized or started.

## 1. API — `scripts/engine/equipment/equipment-grip-resolver.js`
`resolveEquipmentGrips({ occupancy, wielderSize, speciesPermissions?, weapons })`
- `occupancy`: a complete `resolvePhysicalOccupancy()` result. `speciesPermissions`: an E3-A1 result, optional. `wielderSize`: a size name (missing or invalid is indeterminate, not an error).
- `weapons[]`: `{ itemId, shape, ownedState?, gripOption?, beneficialSizeChoice?, tripodMounted? }`. `shape` is a weapon-runtime attack shape (`size`, `sizeRules`, `wielding`, …). Facts are matched to occupancy assignments by `itemId` only — never by name or description. A caller-supplied `requiredHands` (top-level or in the shape) is rejected (`FORBIDDEN_OVERRIDE`).
- Imports only two pure weapon-runtime modules: `wielding-size.js` (`resolveEffectiveWieldingSize`, `sizeStateOf`, `sizeIndexOf`) and `owned-state.js` (`resolveWielding`). No size table or grip rule is duplicated, and the current source precedence (explicit option > owned state > mandatory two-handed > effective-size requirement) is the authority's.
- Result (deterministic, independently owned, deeply frozen): `status`, `occupancyStatus`, `wieldAssignmentCount`, `assessments[]` (per assignment: `itemId`, `weaponIdentityKey`, `purpose`, `appendageIds`, `assignedAppendageCount`, `requiredHands`, `grip`, `occupancyStatus`, `status`, the canonical size verdict `canonicalSize`, the canonical wielding verdict `canonicalWielding` with its original `reason`, `issues`), `simultaneousTwoHanded` (`{count, permissionId, verified}`), `conflicts`, `pendingConstraints` (from occupancy, still unevaluated), `issues`, `speciesPermissions`.

## 2. Verdict semantics
- **`grip-blocked`:** the canonical authorities refuse (`too-large-to-wield`, `below-minimum-wielder-size`, `requires-two-hands`, `cannot-wield-two-handed`), or the assignment has fewer or more appendages than the established grip, or the physical occupancy is blocked.
- **`indeterminate`:** wielder size unknown or invalid, canonical weapon size missing, the tripod state unestablished and grip-relevant (including `grip-requires-tripod-confirmation`, kept as an unknown with its original reason), no grip established, any physical or species-permission evidence unresolved, or a worn / host-mounted configuration.
- **`grip-supported`:** every wield assignment has a verified canonical grip, the right number of physically capable appendages and no open requirement, and the occupancy is `physically-compatible`.
- **Two authority traps handled:** (a) `resolveEffectiveWieldingSize()` can return a non-false `legal` while the classification is unknown, so unknown wielder or weapon size is not treated as positive evidence; (b) `resolveWielding()` can return `legal: true` with `hands` undefined, which is not a verified grip and is never treated as one-handed.
- **Hold assignments** stay physical-holding evidence (`grip: not-assessed-hold-only`); no purpose is changed, and no posture, readiness, attack permission or action cost is produced. `grip-supported` is not readiness. A hold-only set with a compatible occupancy is vacuously supported (`wieldAssignmentCount: 0`).
- **Mounted/worn/integrated:** `shape.worn`, `dualWield.wornNotHeld` and `ownedState.mountedHostId` stay indeterminate (`worn-weapon-configuration-uncertified`, `host-mount-configuration-uncertified`); no zero-hand operation is granted. Tripod state (an existing size-rule input) is used exactly as the size authority defines it.

## 3. Simultaneous two-handed weapons (Codru-Ji)
When two or more verified two-handed wield assignments coexist, an E3-A1 `codru-ji-extra-arms` entitlement (`maxSimultaneousTwoHandedWeapons`) must be verified, otherwise every such assignment is `indeterminate`: `simultaneous-two-handed-weapons-unestablished` (no permission: neither granted nor prohibited), `special-permission-evidence-incomplete` (recognized-incomplete), or `simultaneous-two-handed-count-exceeds-verified-permission`. The real Codru-Ji publication with four arms, two Large weapons on separate arm pairs and the verified permission is `grip-supported`; Killik with the same arrangement is `indeterminate`; one two-handed plus one one-handed weapon needs no special permission. The four-item rule is not made a global limit, and no extra attack is produced.
