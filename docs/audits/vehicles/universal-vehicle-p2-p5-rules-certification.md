# Universal Vehicles — P2/P5 Rules Certification (primary-source review)

Date: 2026-10-30. Branch `audit/universal-vehicles-phase1`. Companion data: `data/audits/vehicles/swse-p2-sotg-modification-evidence.json` (generated by `tools/audits/vehicles/build-sotg-modification-evidence.mjs`, reproducible with `--check`), `data/vehicle-modifications/certification.json`, `data/canonical/vehicles/construction/stock-frames.json`.

## Method and limits
Searched the committed OCR texts in `reference/sourcebooks/` (all 14 books). Per `reference/sourcebooks/README.md` the OCR is the fast layer and **the PDF is final authority** wherever OCR is ambiguous. The OCR has no page markers: every page below is a **table-of-contents section range** (not an exact page). Cells that OCR garbled (e.g. an EP printed as `A`, `Z`, `De`, `ce:`) are flagged `NEEDS_PDF`, never repaired from general knowledge. *Scum and Villainy* and *Knights of the Old Republic* carry only unreadable or non-defining text for these rules.

**A certified row is still not installable**: `MECHANIC_SPECIFIED` requires its effect to be implemented, and the planner returns `MODIFICATION_EFFECT_NOT_IMPLEMENTED` for `SOURCE_VERIFIED` rows. Effects are prose in the books (e.g. shields set the shield rating; armor is an equipment bonus to the armor bonus; reinforced bulkheads add 10/20/30% hit points and do not stack; maneuvering jets give a Dexterity equipment bonus; atmospheric thrusters +10%/+25% speed) and each needs its own implementation and tests.

## 3. Status of the decision register entries
- **V-P2-01** (EP budget): *largely answered by the source.* The spendable figure is the **unused** emplacement points (SotG p. 39). What the source cannot answer is which default to use for hulls whose record states none (426 of 429), what the three KotOR statblock lines ("Emplacement Points: 4/3/2") mean (the text never says "unused"), and one illegible Table 3-2 cell (J-Type transports). Owner decision: Q1, Q2.
- **V-P2-02** (catalog provenance): *partly answered.* 48 rows text-verified, 8 flagged, 126 need the PDF. "Bare Colossal" in a size restriction: Table 3-1 lists plain Colossal as a separate size from its three subtypes, so the book treats it as its own category; the planner already refuses the ambiguous combinations. Owner decision: Q3.
- **V-P2-03** (refund/procedure/effects): *procedure answered* (time, DC, work force, failure results, removal at half time and no cost). *Resale is conditional* ("normally ... if in good working condition and you can find a buyer"), so an automatic refund is a policy choice. Whether the Shipyard should automate the Mechanics check is a workflow choice. Owner decision: Q4, Q5.
- **V-P2-04** (weapon mounts): *the books define an installed weapon's damage, EP, availability and cost, and who fires it (pilot, copilot or gunner), but give no firing-arc rule for installed weapons in any searched book* (arcs appear only as flavor text). The arc requirement is therefore a project policy from earlier phases, not a published rule. Owner decision: Q6.
- **V-P4-01** (Initiative): *partly answered.* Core states the size modifier applies to Initiative and Pilot checks made by a vehicle's occupants and that vehicle Initiative uses the pilot's modifier; it does not say whether a statblock's printed Initiative already includes the size modifier. Separately, the code's table (`SWSECombatDocument._getVehicleSizeModifier`) has no entry for the Colossal subtypes, so frigates, cruisers and stations currently get 0 where Table 10-1 prints -10. Owner decision: Q7.

## 4. Questions for the project owner
1. **(V-P2-01) Default unused EP.** For a hull whose record states none, may the Shipyard apply the book's rule (generally 1; Corellian Engineering Corporation 5; Table 3-2 designs; the Rebellion Era ships that state theirs: Dunelizard 3, Mobquet medium transport 10, Nova Courier 5), or must each hull state its own figure? And do the KotOR "Emplacement Points: N" lines mean unused points?
2. **(V-P2-01) Shortfall.** The book allows an install beyond the unused EP with penalties (+2 days, +5 DC, +20% cost per missing point; ship becomes used). Allow it (GM may forbid per modification) or deny?
3. **(V-P2-02) Certification threshold.** May the 48 OCR-verified rows be treated as certified, or does each need PDF confirmation of the exact page first? The 7 noisy rows, `armor-4`, and the 126 weapon/accessory rows need the PDF either way.
4. **(V-P2-03) Resale.** On removal, automatic 25% credit, none, or a GM-entered amount?
5. **(V-P2-03) Procedure.** Should the Shipyard track installation time and the Mechanics check (success, partial, total failure), or treat the purchase as finished work with the check adjudicated at the table?
6. **(V-P2-04) Firing arcs.** Since no arc rule is published for installed weapons: drop the arc requirement for installed weapons (station and target only), or keep arcs as a GM-set house rule?
7. **(V-P4-01) Initiative.** Is the size modifier added on top of a statblock's printed Initiative? And may the Colossal subtypes use the printed -10?
8. **(V-P5-01) New-frame EP pool.** For a ship designed from a stock frame, is the frame's printed "Emplacement Points" figure the pool available for added systems?
9. **(V-P5-02) Design time.** "+1 per every additional 100,000 credits": per full 100,000 (floor) or per started 100,000 (ceil)?
10. **(V-P5-03) Non-starship vehicles.** No published modification or construction rules were found for walkers, tanks, speeders or other ground/air vehicles (the books' modification chapter is for starships; one weapon is "any vehicle or starship of Huge size or larger"). Support them as GM homebrew only, or not at all?

Source gaps that are not decisions (PDF needed): the *Crew Quality* sidebar (Core Rulebook p. 174) is absent from the OCR, so Initiative, Perception, attack bonus, grapple and CL of a newly designed ship cannot be derived yet (`pending` in `previewFrame`); the weapon and accessory tables; the cells listed above; exact page numbers for every cited table.
