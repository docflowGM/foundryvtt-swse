# Phase 3 targeted risk — Clone Wars SPHA and TX-130T

**Original primary PDF:** `SAGA EDITION - Clone Wars Campaign Guide.pdf`, SHA256 `3c1f085b17f5c9e7288dcd1e1141279a61fc914ce7acb9229f6f3d1aa02219e6`. Direct scanned page reviews: printed pp168–169, one-based physical PDF pp169–170.

## SPHA: five designations, one independent printed vehicle statblock

Printed CL16 `Self-Propelled Heavy Artillery` is a Colossal walker with a mutually exclusive main gun option selected from SPHA-T (heavy turbolaser), -I (ion), -V (heavy laser), -C (heavy missile), -M (mass-driver). Its twelve anti-infantry heavy repeating blasters accompany the chosen configuration and are autofire-only. Only the SPHA-C variant has the printed **48 concussion missile** payload. Treating all five primary source declarations as simultaneously installed weapon groups is incorrect; the six source firing-group records are an inventory of the printed options, **not installed hardware certificates**.

The staged source mechanics already retain this distinction. No new vehicle source identity or physical mount is created. Tests lock the one-record/many-source-configurations relationship.

## TX-130T: do not discard the second printed Ranged declaration

The printed Clone Wars p169 CL7 TX-130T has two distinct Ranged summaries:
- First: laser cannon **+3** plus twin laser +1 plus missile +1.
- Second (later composite-turret variant): laser **+1** plus twin laser +1 plus missile +1 plus composite beam +1.

The detailed laser cannon row is **+3**. That leaves an original print mismatch between the second Ranged summary's +1 and the detailed row's +3. No owner-approved effective reinterpretation was found in this checkpoint. Both original print values remain preserved and the anomaly is explicitly recorded. The existing stage had compressed the two alternatives into one source Ranged line; this checkpoint restores both source sequences without selecting an effective attack.

The **optional astromech** affects starred skill modifiers (Mechanics/Use Computer) and is a separate option from the **later added turret**; neither is automatically installed. One publication-specific TX-130T identity remains in this book, separate from the *Force Unleashed Campaign Guide*'s CL8 TX-130T.
