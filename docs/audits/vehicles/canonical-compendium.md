# Canonical vehicle compendium

**Source:** `data/canonical/vehicles/ships.json` (316 physical lines, one complete ship object per line).

This is **JSON Lines/NDJSON** with the `.json` filename requested for convenient source management. It is not a standard JSON array. Ship identity is `sourceBook + sourceEntryKey`, so identical names in different publications remain distinct. Each line retains printed source facts, source-verified attack-group observations, conflicts, and any approved effective-rule corrections.

**Generated compendium file:** `packs/vehicles-canonical-ships.db` (316 physical lines of Foundry `Actor` JSON). This file is generated, not an alternative authority. It is source-form NeDB and **not** the native Foundry v13 LevelDB directory.

**Native compendium:** `packs/vehicles-canonical-ships/` (generated by the official pinned Foundry CLI 3.0.5 and verified by extraction/round-trip). Existing source review files and subtype vehicle packs are not overwritten.

Commands:

```sh
node tools/vehicles/build-canonical-ships.mjs --write
node tools/vehicles/build-canonical-ships.mjs --check
npm install --prefix /tmp/swse-ships-cli --no-audit --no-fund @foundryvtt/foundryvtt-cli@3.0.5
node tools/vehicles/compile-canonical-native.mjs --cli-root /tmp/swse-ships-cli/node_modules --out /tmp/swse-ships-built
```

The dedicated Actions workflow builds both generated outputs and commits only after the native round-trip passes. It runs on this feature branch and can be dispatched manually.

**Important:** The production `system.json` manifest is deliberately unchanged pending verified native pack output. Before release, declare `vehicles-canonical-ships` as an Actor pack pointing at `packs/vehicles-canonical-ships`, then route the canonical vehicle browser/importer through that pack directly without the legacy normalizer. The old subtype packs should stay intact for ground vehicles and for migration fallback until world-Actor migration is explicitly approved.

**Mechanics policy:** Printed attack groups are readable source evidence, not physical weapon mounts. The generated `system.weapons` remains empty, and no flags grant attack permission. Missing PDF fields remain absent; absent SR is not silently zero. A subset of 17 last-tranche records has only navigation text rather than completely structured `printedFacts`; their unmapped mechanical attributes remain explicitly incomplete. The 15 approved SotG adjudications are preserved alongside the original printed values. Two historical out-of-census records (Hornet, Deep-X) are still excluded pending explicit identity amendment.

Status at branch start: 316/316 source identities, conversion code and CI pipeline present. This is not yet a runtime installation verification or a released manifest cutover.
