# SWSE Sourcebook Text References

These files are OCR/DjVu text exports used as the fast searchable source layer for SWSE rules verification and development.

## Authority rule

- Search the TXT file first for headings, talent names, rules text, prerequisites, source context, and nearby wording.
- When OCR, page layout, punctuation, tables, or same-name identity is ambiguous, the corresponding PDF remains the final source authority.
- Do not silently "correct" source text from general knowledge. Flag ambiguity and verify against the PDF or an already certified canonical audit.
- Preserve sourcebook boundaries. Prefer the individual book file over a combined corpus when identifying publication ownership.
